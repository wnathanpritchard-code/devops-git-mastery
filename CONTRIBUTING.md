The main development code is "main".
Forks should follow the following format:
feature/ for any new feature code.
bugfix/ for any bug fix code.
release/ for release versions.

Be sure to rebase your code prior to entering a pull request.

Once testing has been confirmed that your code does not add any new bugs and your pull request is approved, your branch will be deleted.  Any new features or bugfixes must start a new branch.

Have a nice day and have fun coding.
